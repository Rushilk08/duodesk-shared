# DuoDesk (Android)

**Your space. Our progress.**

DuoDesk is a calm, minimal collaborative productivity Android application built with Kotlin, Jetpack Compose, Material 3, Room, DataStore, and Navigation Compose.

## Features

- **Dual-Workspace Model**: Clean separation between **My Space** (strictly private to the active user) and **Shared Space** (collaborative tasks, assignments, reminders, notes/checklists, and documents).
- **Quick Profile Switching**: Switch seamlessly between **Rushil** (User A) and **Alex** (User B) from the Login or Profile screens to test private vs. shared visibility isolation.
- **Today's Progress Home**: Animated circular progress ring, today's tasks checklist, and compact upcoming deadlines.
- **Calendar**: Interactive **Week**, **Month**, and **Day** views with personal (blush pink) and shared (lavender) color coding.
- **Create & Inspect**: Full creation flow and modal bottom-sheet editor for Tasks, Reminders, Assignments, Notes/Checklists, and Documents with native Android file/document picking.
- **Warm Cream & Soft Dark Themes**: Light and dark themes persisted via Jetpack DataStore.
